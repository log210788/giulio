## 🏛️ Executive Summary & Pedagogical Architecture

This repository hosts the interactive, single-page web companion prepared for Giulio's first lesson. In this session, Giulio and Louie tackled the core cognitive hurdle common to advanced language learners: the **mental translation bottleneck**—the split-second pause where ideas are composed in Spanish before being translated into English. 

Using timed descriptive exercises (*Heads Up*), fine emotional distinctions (*apologetic* vs. *pathetic*, *envious* vs. *suspicious*), British collective animal nouns (*a murder of crows*), and deep discussions on the cultural value of the cinema as an unplugged escape from smartphone notifications, we established a warm, high-confidence foundation for effortless spoken fluency.
